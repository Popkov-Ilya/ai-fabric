TASK TITLE
Two Sum Solver

GOAL
Write a program that returns the indices of two numbers in an integer array whose sum equals the given target.

PROGRAM BEHAVIOR
The program receives an array of integers and a target integer.
It finds exactly two different elements whose sum equals the target.
It returns their indices in any order.

INPUT
Input comes from standard input.
Input format: JSON object with two fields:
- nums: array of integers
- target: integer

INPUT EXAMPLE
{"nums": [2, 7, 11, 15], "target": 9}

OUTPUT
Output must be printed to standard output.
Output format: JSON array containing two integer indices.

OUTPUT EXAMPLE
[0, 1]

RULES AND LOGIC
Use each array element at most once.
There is exactly one valid solution.
Return the indices, not the values.
The answer may be returned in any order.
The solution should handle duplicate numbers correctly.

ERROR HANDLING
If the input is missing, malformed, or does not contain nums and target, raise an error.
If nums has fewer than 2 elements, raise an error.
If no solution is found, raise an error, even though valid test cases always contain one solution.

IMPLEMENTATION REQUIREMENTS
Python version: Python 3.10 or newer.
Dependencies: use only the Python standard library.
Execution: the result must run as python output.py.
Command-line arguments: none.

CONSTRAINTS
2 <= nums.length <= 10000
-1000000000 <= nums[i] <= 1000000000
-1000000000 <= target <= 1000000000
Time complexity should be O(n).
Do not use the same element twice.

ACCEPTANCE CRITERIA
The program starts without syntax errors.
The program solves all provided examples.
The program handles duplicate numbers correctly.
The program returns valid indices for every valid input.
The response must contain only complete Python code suitable for direct writing to output.py.
